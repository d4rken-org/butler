Butler is a file explorer for Android.

Open several tools in tabs, put them side by side, and keep working where you left off.

Download User guide

Android 8.0+ · No ads · No tracking · Open source
Butler is in beta.

What it does

  • Tabs for Explorer, Search, Editor, Apps and History. Show several side by side; some layouts need Pro. Tabs and panes
  • Copy and move files. Restore deleted files from trash. Trash is not a backup.
  • Search file names or contents, with regex. Edit text files.
  • Connect to SMB shares, SFTP and WebDAV servers. Adding and testing is free; browsing needs Pro.
  • Optional root, Porter or Shizuku access for restricted locations. Setup & permissions
