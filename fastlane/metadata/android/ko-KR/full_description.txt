Butler는 탭을 중심으로 만든 Android 파일 관리자예요. 저장공간 전체에서 파일을 탐색하고, 검색하고, 보고, 편집하세요. 다중 패널 레이아웃과 필요할 때 쓸 수 있는 루트 접근도 지원해요.

제가 늘 원하던 Android 파일 탐색기라서 직접 만들었어요. 빠르고, 개인정보를 보호하며, 오픈 소스예요.

Butler는 내장 저장공간, SD 카드, USB OTG 드라이브를 지원하고, Butler Pro에서는 네트워크 공유도 사용할 수 있어요. 갤러리에 보이는 미디어뿐 아니라 모든 파일 유형을 다뤄요.

<b>탭과 작업공간</b>
- 탭에서 파일을 탐색하고 Butler의 여러 도구를 동시에 실행하세요.
- 탭 관리자로 탭을 정리하고 탭 선택기에서 새 탭을 시작하세요.
- 휴대전화와 태블릿에서 다중 패널 레이아웃을 사용하고 패널 간에 항목을 끌어다 놓으세요.
- 즐겨찾기를 고정하고 저장공간 위치를 추가하세요.

<b>파일 작업</b>
- 복사, 이동, 이름 변경, 삭제를 지원하고 작업 중 전송 속도와 성능 그래프를 보여줘요.
- 휴지통을 지원해 삭제한 파일을 되돌릴 수 있어요.
- 압축 파일을 폴더처럼 여세요. ZIP, TAR, APK 번들을 먼저 풀지 않고 바로 탐색할 수 있어요.
- ZIP 압축 파일을 만들고, 암호화된 압축 파일도 해제할 수 있어요.
- 앱을 나가도 작업은 계속 진행돼요. 알림에서 진행 상황을 확인하고 취소할 수 있어요.
- 작업 기록에서 실행한 작업과 성공 또는 실패 여부를 확인하세요.

<b>네트워크 공유(Butler Pro)</b>
- SMB로 Windows 공유 폴더와 NAS 폴더에 연결하고 다른 저장공간처럼 탐색하세요.
- 기기와 서버 사이에서 양방향으로 파일을 복사하고 이동하세요.
- 게스트로 로그인하거나 사용자 이름과 비밀번호로 로그인하세요. 로그인 정보는 이 기기에만 암호화되어 저장돼요.
- 공유 위치 추가와 연결 테스트는 무료예요. 탐색하려면 Butler Pro 업그레이드가 필요해요.

<b>검색과 텍스트</b>
- 파일 이름과 파일 내용으로 검색하세요. 정규식(regex)도 지원해요.
- 아주 큰 파일도 빠르게 다루는 텍스트 편집기를 제공해요.

<b>파일 보기</b>
- Butler 안에서 이미지를 보고 PDF 페이지를 넘겨 보세요.
- 파일 크기, 가로·세로 크기, 권한, 소유자까지 자세히 확인하세요.
- 필요할 때 폴더 크기를 계산해 무엇이 저장공간을 채우고 있는지 확인하세요.
- Butler에서 직접 표시할 수 없는 파일은 해당 파일을 열 수 있는 앱으로 넘겨줘요.

<b>앱과 APK</b>
- 앱 관리자에서 설치된 앱을 탐색하고, 사용 중지하고, APK를 내보내고, 앱 데이터를 지우고, 앱을 제거하세요.
- APK 파일을 받아 살펴보고 여세요. 설치는 Android 시스템 설치 프로그램을 통해 진행돼요.

<b>다른 앱과 함께 사용</b>
- 다른 앱의 파일 선택기에도 Butler가 나타나요. 파일을 열거나 저장하는 곳 어디서든 Butler로 탐색할 수 있어요.
- 어떤 앱에서든 Butler로 파일을 공유하고, 원하는 이름과 저장 위치를 정확히 선택하세요.
- 공유한 텍스트는 Butler 편집기에서 바로 열려요.

<b>접근과 모양</b>
- Android가 보통 접근을 막는 위치는 Root 또는 Shizuku로 접근하세요.
- 동적 색상, 다크 모드, AMOLED 옵션을 갖춘 Material You 테마를 지원해요.

<b>개인정보 보호</b>
추적하지 않아요. 분석 SDK도, 계정도, 클라우드도 없어요. 직접 보내기로 선택하지 않는 한 비정상 종료 및 오류 보고서는 기기에만 남아요. 오픈 소스예요.

파일 관리자는 저장공간 전체에 접근해야 하므로 Butler는 "모든 파일 접근" 권한을 요청해요. 모든 작업은 기기 안에서 이뤄져요.

이 앱에는 광고가 없어요. 일부 기능은 유료 업그레이드가 필요해요.

Butler는 Android용 파일 관리자이자 파일 탐색기, 텍스트 편집기예요.
