Butler 是一款以分頁為核心的 Android 檔案管理工具。透過多窗格版面配置，瀏覽、搜尋、檢視及編輯整個儲存空間中的檔案，並在需要時使用 Root 存取權。

這就是我一直想要的 Android 檔案總管，所以我自己做了一個。快速、保護隱私，而且開放原始碼。

Butler 支援內部儲存空間、SD 卡和 USB OTG 隨身碟，搭配 Butler Pro 還能存取網路共用資源。不只相簿裡的媒體，更能管理所有類型的檔案。

<b>分頁與工作區</b>
- 以分頁瀏覽檔案，同時使用 Butler 的各種工具。
- 使用分頁管理員整理分頁，並透過分頁選擇工具開啟新分頁。
- 手機和平板電腦皆支援多窗格版面配置，可在窗格之間拖放項目。
- 釘選我的最愛，並新增其他儲存位置。

<b>檔案操作</b>
- 複製、移動、重新命名及刪除，操作時可查看傳輸速度與效能圖表。
- 支援回收桶，讓刪除的檔案仍可還原。
- 像資料夾一樣開啟壓縮檔：直接瀏覽 ZIP、TAR 及 APK 套件，不必先解壓縮。
- 建立 ZIP 壓縮檔，並解壓縮一般及加密壓縮檔。
- 離開應用程式後，操作仍會繼續執行，通知中會顯示進度與取消按鈕。
- 操作歷史記錄會顯示執行過的操作，以及成功或失敗的結果。

<b>網路共用資源 (Butler Pro)</b>
- 透過 SMB 連線至 Windows 共用資料夾與 NAS 資料夾，像其他儲存空間一樣瀏覽。
- 在裝置與伺服器之間雙向複製及移動檔案。
- 以訪客或使用者名稱與密碼登入，登入資訊僅以加密方式儲存在你的裝置上。
- 新增共用資源與測試連線皆可免費使用。瀏覽則需要升級至 Butler Pro。

<b>搜尋與文字</b>
- 依檔案名稱及檔案內容搜尋，支援正規表示式 (regex)。
- 即使編輯非常大的檔案，文字編輯器依然快速流暢。

<b>檢視檔案</b>
- 不必離開 Butler，就能檢視圖片及逐頁瀏覽 PDF。
- 檢視詳細檔案資訊，包括大小、尺寸、權限及擁有者。
- 隨時計算資料夾大小，找出真正佔用儲存空間的內容。
- Butler 無法自行顯示的內容，會交由能開啟它的應用程式處理。

<b>應用程式與 APK</b>
- 應用程式管理員：瀏覽已安裝的應用程式、停用、匯出 APK、清除應用程式資料及解除安裝。
- 接收、檢查及開啟 APK 檔案。安裝會透過 Android 系統安裝程式進行。

<b>與其他應用程式搭配使用</b>
- Butler 會出現在其他應用程式的檔案選擇工具中，讓你在開啟或儲存檔案時都能使用 Butler 瀏覽。
- 從任何應用程式將檔案分享到 Butler，自行選擇儲存位置與檔案名稱。
- 分享的文字會直接在 Butler 的編輯器中開啟。

<b>存取權與外觀</b>
- 使用 Root 或 Shizuku 存取 Android 通常不開放的位置。
- 採用 Material You 主題，支援動態色彩、深色模式及 AMOLED 選項。

<b>隱私</b>
不追蹤。不含分析 SDK、不需帳戶，也不使用雲端。當機與錯誤報告會留在你的裝置上，除非你選擇傳送。開放原始碼。

Butler 會要求「所有檔案存取權」，因為檔案管理工具需要存取整個儲存空間。所有操作都在你的裝置上進行。

本應用程式無廣告。部分功能需要付費升級。

Butler 是適用於 Android 的檔案管理工具、檔案總管與文字編輯器。
